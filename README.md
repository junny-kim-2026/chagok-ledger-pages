# 차곡 가계부

매일의 수입과 지출을 기록하고 일별·월별·연도별 합계를 보는 개인용 가계부입니다.

## 내 컴퓨터에서 열기

이 폴더의 `index.html`을 더블클릭하세요. 프로그램 설치는 필요 없습니다. 파일들은 같은 폴더에 두세요.

## 사용 방법

1. **내역 추가**를 눌러 수입 또는 지출, 금액, 날짜, 항목을 입력하고 저장합니다.
2. **일별·월별·연도별** 버튼과 날짜 선택으로 원하는 기간을 봅니다.
3. 각 기록의 **수정·삭제** 버튼으로 내역을 관리합니다.
4. **백업 파일 저장**으로 기록을 별도 파일에 보관합니다. **백업 복원**은 현재 기록 전체를 선택한 백업으로 교체합니다.

월말 잔액은 전월 이월금 + 이번 달 수입 − 이번 달 지출입니다. 저장된 모든 이전 거래를 기준으로 계산하며, 기록이 없는 달이나 연도가 바뀌어도 이어집니다. 과거 내역을 수정·삭제하면 이후 잔액도 다시 계산합니다. 이월금은 별도의 수입으로 추가되지 않습니다. 일별은 전일 이월금, 연도별은 전년 이월금을 포함합니다. 초기 잔액은 0원이며 은행 계좌와 연결되지 않습니다. 선택 기간 안에 미리 기록한 미래 날짜의 거래도 잔액에 포함됩니다.

## 저장과 개인정보

- 기록은 서버가 아니라 현재 브라우저의 저장 공간(localStorage)에 저장됩니다.
- 다른 사람에게는 그 사람의 브라우저에 저장된 기록만 보입니다. 초기 기록은 비어 있습니다.
- 다른 기기나 브라우저와 자동으로 동기화되지 않습니다. 시크릿 모드는 기록 보관용으로 쓰지 마세요.
- 브라우저 데이터 삭제, 파일 이동, 사이트 주소 변경 전에 백업하세요.
- 컴퓨터의 파일에서 입력한 기록은 GitHub Pages로 자동 이전되지 않습니다. 기존 파일에서 백업한 뒤 새 사이트에서 복원하세요.
- 같은 GitHub 계정의 다른 Pages 사이트와 브라우저 저장 공간이 같은 출처를 사용할 수 있습니다. 신뢰할 수 없는 다른 앱을 같은 출처에서 운영하지 마세요. 로그인·암호화 기능은 없습니다.
- 백업 파일에는 본인이 입력한 거래와 메모가 들어 있습니다. **GitHub에 백업 파일이나 실제 거래 자료를 올리지 마세요.**

## 이 폴더의 파일

- `index.html`: 처음 열리는 화면
- `style.css`: 색상과 화면 배치
- `app.js`: 계산, 기록 관리, 브라우저 저장 및 백업 기능
- `favicon.svg`: 브라우저 탭의 작은 아이콘
- `.nojekyll`: GitHub Pages가 파일을 그대로 제공하게 하는 빈 파일
- `.gitignore`: 임시 파일과 백업을 Git 작업에서 제외하는 목록
- `README.md`: 이 설명서

모든 화면 파일은 상대 경로로 연결되어 있습니다. 서버, Cloudflare, ChatGPT Sites 설정이나 설치 파일은 필요하지 않습니다.

## GitHub Pages에 올리기

1. 압축을 풀고 **이 폴더 안의 파일들**을 GitHub 저장소 맨 위에 올립니다. `index.html`이 저장소의 첫 화면에 보여야 합니다.
2. 저장소에서 **Settings → Pages**를 엽니다.
3. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
4. 올린 파일이 있는 브랜치(보통 `main`)와 **/(root)**를 선택하고 **Save**를 누릅니다.
5. 게시가 끝나면 Pages 설정 화면에 표시되는 주소로 접속합니다.

현재 GitHub Pages에 게시되어 있으며 main 브랜치를 갱신하면 다시 배포됩니다.

주의: `.gitignore`는 Git 도구에 적용됩니다. GitHub 웹 화면에서 직접 파일을 올릴 때 개인정보 파일을 자동으로 막아 주지는 않습니다. 이 폴더 밖의 `ledger`, `work`, 설치 기록, 개인 백업 파일을 함께 올리지 마세요.

공식 게시 안내: [GitHub Pages 게시 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 고정 지출

**고정 지출 등록**에서 이름·금액·매월 지출일·항목을 저장합니다. **기록할 월**을 고른 뒤 각 항목의 **월에 기록** 버튼으로 지출을 넣습니다. 자동 결제나 백그라운드 자동 입력은 하지 않습니다. 같은 등록은 같은 달에 중복 입력되지 않으며, 31일 등이 없는 달은 말일에 기록합니다. 거래를 삭제하면 다시 기록할 수 있습니다. 등록 수정·삭제는 기존 거래 내역을 바꾸지 않습니다.

백업에는 고정 지출 등록도 함께 들어갑니다. 예전 백업도 복원할 수 있지만, 고정 지출이 없는 예전 백업으로 교체하면 현재 고정 지출 등록도 없어집니다. 새 백업은 최신 앱에서 복원하세요.

## 달별 메모장과 계산기

메모할 월을 고르고 글을 쓴 뒤 **메모 저장**을 누르세요. 다른 달로 이동할 때도 저장합니다. 저장 실패 시 입력을 유지합니다. 계산기에 `12,000 + 3,000 * 2`처럼 입력하고 **계산하기**를 누르세요. 결과를 메모에 넣은 뒤 저장할 수 있습니다. 계산 결과는 소수점 아래 8자리까지 반올림하며 거래 합계에는 영향을 주지 않습니다.

월별 메모도 백업에 포함됩니다. 이전 버전 백업에는 메모가 없으므로 복원 시 저장된 메모도 교체됩니다. `notes.js`는 메모와 계산 기능 파일입니다.

## 용도별 미니 가계부 3개

각각 **이름 변경**으로 여행비·회비·비상금 등 용도를 정하세요. **입출금 기록**에서 입금 또는 출금과 금액을 입력하고 저장합니다. 날짜는 오늘로 채워지며 바꿀 수 있습니다. 각 가계부의 총입금·총출금·잔액은 전체 기간 누적 금액입니다. 본 가계부와 다른 미니 가계부 합계에는 영향을 주지 않습니다. **입출금 내역**을 펼치면 수정·삭제할 수 있습니다.

미니 가계부 이름과 내역도 백업에 포함됩니다. 예전 백업을 복원하면 미니 가계부는 빈 상태로 교체됩니다. `mini.js`는 이 기능을 담당합니다.
